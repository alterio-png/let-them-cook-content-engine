- All changes on feature branches, PR and CI. Do not merge automatically.
- Do not install or execute any GitHub candidate without G1-G4 authorization and isolated dependency review.
- Do not use third-party downloads, customer assets, accounts, credentials or cloud resources without scoped permission.
- No scraping or republishing third-party content without documented rights.
- No production publication until API permissions, idempotency and human approval are validated.
- Never report G0 smoke tests as production readiness, AI quality validation, cloud load validation or SaaS delivery.
- No unbounded FFmpeg work. Apply size, duration, CPU/memory, timeout and user quotas.
- Preserve organization isolation, immutable request fingerprint, artifact checksums and the ability to reconcile partial operations.
- Add tests for failure modes and prove prior audit claims before new capability.
